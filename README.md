# Trainora – Premium Landingpage

Vollständiger statischer Export im Navy-/Türkis-Design.
Start: ZIP entpacken und index.html öffnen. Für den Kopierbutton kann ein lokaler Webserver oder HTTPS nötig sein.

## Dateien
index.html, datenschutz.html, impressum.html, style.css, app.js, theme.js und assets/.
Kein Build, keine Installation und kein Backend erforderlich.
Die Landingpage ist Deutsch; die Versionshinweise 0.3 sind Deutsch und Englisch.

## GitHub Pages
Die Dateien aus diesem ZIP direkt in den vorgesehenen Veröffentlichungsordner des gewünschten Repositorys hochladen. index.html muss dort auf oberster Ebene liegen. .nojekyll ist enthalten. Relative Links funktionieren auch unter einem Repository-Unterpfad. Die GitHub-Pages-Konfiguration des Zielrepositorys muss auf diesen Ordner zeigen.
